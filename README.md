# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer shopping behavior using Python, PostgreSQL, SQL, and Power BI. The goal is to explore purchasing patterns, customer preferences, discount usage, subscription behavior, and revenue across different customer groups.

The project follows an end-to-end data analytics workflow, from data cleaning and preparation to SQL-based analysis and interactive dashboard creation.

## Objectives

- Clean and prepare customer shopping data for analysis.
- Handle missing values and standardize column names.
- Create additional features such as age groups and purchase frequency in days.
- Use SQL to answer business-related questions.
- Build an interactive Power BI dashboard to visualize key metrics and trends.
- Identify potential business opportunities based on the analysis.

## Tools and Technologies

- **Python:** Data preparation and feature engineering
- **Pandas:** Data manipulation and cleaning
- **Jupyter Notebook:** Python development environment
- **PostgreSQL:** Database storage and management
- **SQL:** Data querying and business analysis
- **Power BI:** Dashboard development and data visualization

## Project Workflow

### 1. Data Preparation Using Python

- Loaded and explored the dataset using Pandas.
- Inspected data types, summary statistics, and missing values.
- Filled missing review ratings using the median rating within each product category.
- Standardized column names.
- Created age groups using quartiles.
- Converted purchase frequency categories into approximate day intervals.
- Checked for redundancy between promotional columns and removed the redundant column after verification.

### 2. Database Integration

Loaded the cleaned dataset from Python into a PostgreSQL database using SQLAlchemy.

### 3. SQL Analysis

Used SQL queries to investigate the following business questions:

1. What is the total revenue generated by male and female customers?
2. Which customers used discounts but spent at or above the average purchase amount?
3. Which five products have the highest average review ratings?
4. How do average purchase amounts compare between Standard and Express shipping?
5. How do subscribers and non-subscribers compare in customer count, average spending, and total revenue?
6. Which five products have the highest percentage of purchases with discounts applied?
7. How can customers be segmented based on their previous purchases?
8. What are the top three most purchased products within each category?
9. How many repeat buyers fall into each subscription-status group?
10. How is total revenue distributed across age groups?

### 4. Power BI Dashboard

Created a dashboard containing:

- **KPI cards:** Number of Customers, Average Purchase Amount, and Average Review Rating
- **Subscription analysis:** Customer distribution by subscription status
- **Category analysis:** Revenue and sales by product category
- **Age-group analysis:** Revenue and sales by age group
- **Interactive slicers:** Subscription Status, Gender, Category, and Shipping Type

## Dataset

The dataset contains 3,900 records and 18 original columns covering customer demographics, purchases, product categories, discounts, subscription status, review ratings, and shipping preferences.
